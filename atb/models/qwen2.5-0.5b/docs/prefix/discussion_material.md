## 2. 优化方案收益对比

### 方案 A: Fused Pre/Post (不重写 FIA)

将 GatherV2 融入相邻算子, QKV 权重合并, 消除独立 GatherV2 launch:

**Fused_Pre**: `RmsNorm → QKV_merged → Split → RoPE → Expand` (1320 tokens, 输出 1500 给 FIA)
**Fused_Post**: `Compress → O_proj → Add+RmsNorm` (1500→1320, 输出给 FFN)

| 模块 | 基线 (us) | 理论优化 (us) | 实际预期 (us) | 理论加速比 | 实际加速比 | 主要收益来源 |
|------|----------|-------------|-------------|-----------|-----------|------------|
| Fused_Pre | 1,530 | 1,224 | 1,282 | 20.0% | 16.2% | QKV merge + launch 吸收 |
| FIA | 2,724 | 2,724 | 2,724 | 0% | 0% | 无变化 (1500 tokens) |
| Fused_Post | 1,019 | 831 | 865 | 18.4% | 15.1% | O proj + launch 吸收 |
| FFN | 5,217 | 4,715 | 4,790 | 9.6% | 8.2% | Token reduction |
| Tail | 111 | 108 | 108 | 3.2% | 3.2% | Sub 消除 |
| **总计** | **10,601** | **9,602** | **9,770** | **9.4%** | **7.8%** | |

| 收益类型 | 理论 (us) | 实际 (us) | 占比 | 置信度 |
|---------|----------|----------|------|--------|
| Token reduction (1320 vs 1500) | 628 | 534 | 5.0% | 高 |
| Fusion (QKV merge + launch + mem) | 368 | 294 | 2.8% | 中 |
| Sub elimination | 4 | 4 | 0.0% | 高 |
| **总计** | **999** | **832** | **7.8%** | |

### 方案 B: 重写 FIA + Fused Pre/Post

在方案 A 基础上, 新写 FA 支持 shared prefix (block-structured attention):

```
Full attention matrix:     1500 × 1500 = 2,250,000 elements
Shared prefix matrix:      prefix² + (B-1)×(S-P)×(P+S-P) = 175,900 elements (-92.2%)
```

FIA 92.8% 是固定开销 (tiling/scalar/mte2), attention 矩阵缩减只能省 O(n²) 部分:

| 模块 | 基线 (us) | 理论优化 (us) | 实际预期 (us) | 理论加速比 | 实际加速比 | 主要收益来源 |

| Fused_Pre | 1,530 | 1,224 | 1,282 | 20.0% | 16.2% | 同方案 A |
| FIA (重写) | 2,724 | 2,261~2,574 | 2,409~2,574 | 5.4~17.0% | 5.7~11.5% | Attention 矩阵 -92% |

### 两方案对比

| 维度 | 方案 A (Fused Pre/Post) | 方案 B (重写 FIA + Fused) |
|------|----------------------|------------------------|
| 实际预期收益 | **7.8%** | **9.3~10.8%** |
| 额外收益 | — | +1.5~3.0% (FIA attention 矩阵缩减) |
| 工程量 | 中 (2 个 fused kernel) | 高 (2 个 fused + 1 个自定义 attention) |
| FIA 改动 | 无 | 需重写 (block-structured attn) |
| 风险 | 低 (算子融合, 逻辑不变) | 中 (attention 正确性, 性能不确定) |
| 收益置信度 | 高 (token reduction 可靠) | FIA 部分低 (92.8% 固定开销, 压缩空间小) |

### FIA 重写收益不确定的原因

```
FIA per-call 分解 (113.5 us/call, 1500 tokens):
  AIC mte2 (K/V loading):   37.8 us (33%)  ← O(n), 预加载, 不随 attn矩阵变化
  AIC scalar:               52.9 us (47%)  ← 部分固定, 部分O(n²)
  AIC fixpipe:              15.5 us (14%)  ← 大部分固定
  AIC mac (Q×K^T, softmax×V): 3.2 us (3%)  ← 纯O(n²), 但太小
  AIV (全部):              106.7 us        ← 与AIC并行, 大量固定开销

attention 矩阵 -92%, 但:
  mac 只占 3% → 最多省 70 us/iter
  scalar/fixpipe 部分O(n²) → 估计省 80~330 us/iter
  mte2 是O(n) → 不省
  AIV 固定开销 → 不省
  → FIA 额外节省 150~400 us (1.4~3.8%), 置信度低
```
